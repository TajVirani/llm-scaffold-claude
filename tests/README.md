# Tests

Scaffold-only. This folder tests the scripts and hooks in `.agents/`, the root `install.sh` and `scripts/upstream-diff.sh`, and lints `upstream-lineage.json`, the `.claude/` shim and `PLAN/decision-flow*`. It is not part of the install payload: `install.sh` copies only what `.agents/install-manifest.txt` lists and leaves out `tests/`, like `PLAN/`, `assetlist.md`, `checklist.md`, `upstream-lineage.json`, `wayfinder-comparison.html`, `testprompt.md` and the scaffold repo's own `.workflow/` (D30). Nothing in `.agents/` may depend on it.

## Requirements

- bash 3.2 or newer (macOS default is fine; no bash 4 features are used)
- git
- jq
- [mikefarah yq](https://github.com/mikefarah/yq) v4 (not the Python `yq`)
- shellcheck

`run-all.sh` checks these first and exits 2 with an install hint if one is missing. A suite run directly skips its shellcheck assertion when shellcheck is absent and reports it as `skip`.

## Run

```sh
tests/run-all.sh                       # every suite, then a summary; exit 1 if any suite failed
tests/run-all.sh --suite pre-launch    # one suite (name without .sh; --list shows them)
tests/run-all.sh --suite pre-launch --suite lint/symlinks   # several suites: repeat --suite; they run in --list order
tests/run-all.sh -v                    # print each suite's full output instead of failures only
tests/run-all.sh --only-file F         # only the suites F names, one per line (tests/scripts/NAME.sh or scripts/NAME)
tests/run-all.sh --covering-file C     # the suites that cover the changed files C lists (one repo-relative path per line): a suite
                                       # that is the file, whose text names the file's basename, or any lint suite for a markdown file;
                                       # added to --only-file's suites; a file no suite covers is named on stderr and selects nothing
tests/run-all.sh --exclude-file G      # every suite except those G names; with --only-file or --covering-file, the selection minus G
tests/run-all.sh -j 1                  # one suite at a time (default: as many at once as there are CPUs, else 4)
bash tests/hooks/write-guards.sh       # a suite directly
TEST_BASH=/bin/bash tests/run-all.sh --suite status-transition-specs   # run the scripts under another bash
```

Every suite takes under a minute. The `install.sh`, `status-transition.sh` and `check-write.sh` suites are split by concern so no single suite holds up a parallel run.

Suites run in parallel, but each suite's output is held until it finishes and printed in `--list` order, so the report reads the same as a `-j 1` run apart from timings. An empty or missing `--only-file` or `--covering-file` selects every suite; a `--covering-file` with paths selects only the suites that cover them, so one that covers nothing runs no suite. A selector or `--suite` name that names no suite, `--suite` (once or repeated) combined with any of the three files, or a `-j` value that is not a positive whole number exits 2.

When a suite fails, a `-v` run ends with a `== failures` block after the summary: a `-- <suite>` line for each failed suite, followed by its FAIL lines and their indented detail, the same lines the default output shows. A verbose log can then serve as a failure record without being searched.

## CI

The runner is CI-agnostic: install the requirements above, run `tests/run-all.sh`, and treat a non-zero exit as failure. The last line of each suite is `RESULT passed=N failed=M skipped=K xfail=X`, which `run-all.sh` totals.

## Conventions

- Every suite sources `lib/common.sh`, calls `preflight`, and ends with `finish`.
- Fixtures live in a `mktemp` directory removed on exit. In the scripts and hooks suites, components under test are read from a copy of this repo's `.agents/` inside the fixture; lint suites read the repo directly and only read it. A test run never writes to the repo. No absolute or home paths.
- Paths are relative to the repo root (found from the suite's own location) or to the temp dir.
- An `xfail` records a known script defect. It does not fail the run, and it fails the run once the script is fixed, so the test gets updated. There are no current xfails.
- Keep every file shellcheck clean (`shellcheck tests/lib/*.sh tests/fixtures/*.sh tests/scripts/*.sh tests/hooks/*.sh tests/lint/*.sh tests/run-all.sh`).
